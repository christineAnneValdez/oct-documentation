### 4. ⏩ Task Advance Options (Time Quick-Add Feature)
Instead of manually editing the due date, users can choose from quick options such as:

- `+5 min`
- `+1 hour`
- `+1 day`
- `+1 week`
- `+1 month`
- `+90 days`

When a user clicks one of these buttons, the system automatically updates the task’s due date based on the chosen interval.

### 5. 🟢 Task Status management
Tasks can be:

- In Progress
- Failed/Duplicate
- Done
- Backlog
- Trashed

Each status can be toggled with one click.

### 6. 🗂️ Board-based Multi-tenancy
- Create multiple boards to separate projects, teams, or departments.
- Join existing boards through invitations from admins.
- Assign role-based access (Admin/Member) to control permissions and actions.

### 7. 💬 Collaboration
- Comments, file attachments, and tags for enhanced teamwork
